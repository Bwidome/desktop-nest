Desktop Nest · 桌面收纳 v0.3
============================

双击 DesktopNest.exe 就能用。
不需要装 Python，不需要装 PyQt6，不需要任何运行库 —— 全都已经打进包里了。


一、怎么用
----------

1. 把整个文件夹解压到**任意位置**（桌面、D 盘都行）。

   ⚠️ 别只把 DesktopNest.exe 单独拖出来：它和旁边的 _internal 文件夹
      是一体的，少了 _internal 就会启动失败。

2. 双击 DesktopNest.exe。

3. 启动后会发生这些事：
   · 屏幕底部出现一条菜单栏（Dock）
   · 桌面上的文件、文件夹、快捷方式被收进收纳目录，桌面变空
   · 托盘出现程序图标，右键它能看到所有功能

4. 想找回桌面上的东西：
   · 双击托盘图标 / 点菜单栏最左边的「桌面整理」→ 打开收纳面板
   · 或者在托盘右键菜单里点「还原桌面」
   · 退出程序时也会**自动把东西放回桌面**


二、桌面上的东西去哪了
----------------------

暂存在这里（隐藏目录，就是个普通文件夹，随时可以自己去看）：

    C:\Users\<你的用户名>\.desktop-nest\desktop\

程序默认只做"移动"，**不会悄悄删除任何东西**。就算程序崩了、被强制结束，
下次启动也会先把上次没收完的还回去。
真不放心就按下面第四节手动还原。

**唯一会删东西的地方**，是你在收纳面板里主动右键 →「删除（移到回收站）」。
它是删进 **Windows 回收站**（和资源管理器里按 Delete 是同一条路径），
随时可以打开回收站右键还原。盘符根目录、系统文件（desktop.ini 等）
和收纳目录本身会被挡住，删不掉。


三、系统要求
------------

· Windows 10 / 11（64 位）
· 不需要 Python、不需要 PyQt6、不需要任何额外运行库


四、出问题怎么办
----------------

1. **双击没反应**

   先等 10~20 秒：程序要扫描桌面、还要把图标缓存建起来，第一次会慢些。

   还不行就打开命令行（在程序目录的地址栏输入 cmd 回车），执行：

       DesktopNest.exe --selftest

   它会把启动的每个环节检查一遍。诊断信息写在：

       %LOCALAPPDATA%\DesktopNest\app.log
       %LOCALAPPDATA%\DesktopNest\crash.log

2. **桌面空了，想立刻恢复**

   同一个命令行里执行：

       DesktopNest.exe --restore

   它会把收纳目录里的东西全部搬回桌面，然后弹窗告诉你结果。
   **只移动、不删除**，重名会自动加序号。

   （不依赖 `还原桌面.bat` 之类的脚本 —— 那些要机器上先装 Python，
     而发行版的目标机器不一定有。`--restore` 做在 exe 里，永远可用。）

3. **不小心删了东西**

   右键删除是**删到 Windows 回收站**，不是永久删除。
   打开「回收站」找到它，右键 → 还原即可（原始位置会一起恢复）。

4. **被杀毒软件拦了**

   这是 PyInstaller 打包程序的常见误报（不是病毒）。
   把整个文件夹加进杀软白名单即可。


五、几个小提示
--------------

· 菜单栏可以**拖到屏幕任意位置**（横竖都行），位置会记住。
· 按住菜单栏上的图标**长按约 0.3 秒**再拖，可以给常用软件排序：
  被拖的图标跟着鼠标走，其他图标会**像有弹性一样弹开让位**，
  松手后自己弹回最终位置；拖到菜单栏外面松手就取消，顺序不变。
· 在收纳面板里**按住卡片约 0.35 秒**拖到顶部的常用栏，
  松手就把它固定成常用软件，菜单栏会同步出现。
· 面板底部的按钮**跟着你选中的东西变**：
  选中的还不是常用软件 → 显示「加为常用」；已经是常用 → 显示「移出常用」。
  （没选中任何东西时它是灰的。）
· 面板里选中一个条目后，**选中状态会一直留着**，直到你把它打开 ——
  这样你才有时间把鼠标挪到底部按钮上。
· 面板里的收纳内容支持右键：
  打开 / 打开文件所在位置 / 加为常用启动 / 还原到桌面 / 复制完整路径 /
  **删除（移到回收站）**。
· 「此电脑 / 回收站」这类系统图标不显示在面板里（按需求移除）。
· 程序同时只允许开一个：重复双击会把已经在跑的那个的面板叫出来。
· 常用软件加多了菜单栏会自动换行，永远不会跑出屏幕。


六、卸载
--------

直接删掉整个文件夹即可。程序基本不写注册表
（除"开机自启"这一个开关，它写在 HKCU\...\Run 下，在设置里关掉就行）。

桌面上的东西记得先还原出来。
